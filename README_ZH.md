# E2EE-Experiment
简体中文 | [English](README.md) | [AI 协作文档](README_AGENT.md)

> 一个二进制，像一个人：能听，能说，转身即忘。

**E2EE-Experiment** 把一个比喻当了真：*可执行文件就是一个人。*
没有服务器，没有账户，没有数据库——只有一个替你保守秘密、聊完就忘的程序。

> **使用 AI 助手（Copilot / Claude / GPT 等）参与本项目的开发？** 请先阅读
> [README_AGENT.md](README_AGENT.md)——它专为 AI 编写，包含本项目的设计不变量
> 与红线约束，跳过它直接改代码极可能破坏零持久化内核。

## 这是什么

| 人                   | 程序                                 |
|----------------------|--------------------------------------|
| 耳朵                 | 出生即打开 —— 进程一启动就守在端口上 |
| 嘴                   | `/dial` —— 随时主动找人，不必重启    |
| 只有你们俩听得懂的话 | 端到端加密 —— 每场对话全新的钥匙     |
| 转身即忘             | 零持久化 —— 任何东西都不落盘         |
| 认出对面是谁         | **你自己来**，解密之后               |

最后一行是刻意为之。这是安全里的**电话模型**：线路是保密的，
但听筒那头自称是谁，就是谁。系统只承诺**保密**，从不承诺**身份**——
加密从来不等于认证。认出声音——靠暗语、共同记忆、一贯的语气——是人类的
本事，就留在人类手里。（确实需要确认对面是谁，就带外约一句暗号，
见[暗号](#暗号确认对面是谁)。）

## 工作原理

三件事撑起全部安全性：

1. **每场对话都是一把新钥匙。** 每条连接都现场做一次全新的密钥交换——
   攻击者必须**同时攻破**经典算法（X25519）**和**后量子算法（Kyber1024）
   才能读到任何内容：即使有人把今天的流量录下来、等着量子计算机出现，
   也一无所获。对话结束，钥匙随之即焚——前向保密是白送的。
2. **任何东西都不落盘。** 不写配置、不写日志、不存密钥、不留历史。
   进程就是寿命——退出即死亡，死亡即遗忘。
3. **人人平等。** 每份拷贝完全相同，没有服务器/客户端之分，没有特权节点。
   用于 NAT 穿透的可选"茶馆"只搬运它自己都读不懂的字节。

**诚实的威胁模型。** *能防：*线路上的人（ISP、嗅探 Wi-Fi 的人、骨干网
窃听）——他们看到的只有加密帧。*不防（默认）：*主动中继握手的中间人
（电话模型接受的代价——用暗号可以堵上），以及对端本人（对方可以复制、
粘贴、截图）。

### 值得知道的关键细节

- **流量形状混淆**——握手帧和聊天帧带随机垫、文件按随机大小切块：
  同一句话连发八次，八种帧长。被动观察者无法从尺寸指纹读出内容。
- **文件从不走文字车道**——二进制一毫不差地到达，不被文本检查损坏，
  单文件上限 32MB。
- **群聊每次有人加入就换钥**——新成员触发新钥匙；没有花名册可泄露，
  因为从未存储过。
- **上屏的名字永远取自来线，不取自明文**——没人能在对话或群里
  替别人开口。

## 上手

两种方式拿到程序：

- **预编译**——从 [GitHub Releases](https://github.com/Huai-Tian/E2EE-Experiment/releases)
  下载：完全静态的 Linux x86_64（musl，零运行时依赖）、Linux glibc 版、Windows 版。
- **源码构建**——`cargo build --release`，产物在 `./target/release/E2EE-Experiment`。

第一场对话，同一台机器开两个终端：

```bash
# 终端 1 —— Alice 出生，默认在 7777 上听
./target/release/E2EE-Experiment -n Alice

# 终端 2 —— Bob 出生在自己的端口上，然后走去找 Alice
./target/release/E2EE-Experiment -n Bob 127.0.0.1:7778
/dial 127.0.0.1:7777
```

敲一行回车，这一行就会（在途中加密）出现在对面。聊天走 stdout、
连接事件走 stderr——对话本身可以直接接管道。收到的文件落在 `./received/`。

### 启动选项

```
E2EE-Experiment [监听地址] [-n 名字] [选项]
```

| 选项            | 含义                                                                                                                                |
|-----------------|-------------------------------------------------------------------------------------------------------------------------------------|
| *（无）*        | 出生即监听 `0.0.0.0:7777`。同一台机器开两个人要换端口。                                                                             |
| `-n <名字>`     | 自报家门的显示名（别名而已，背后没有任何背书）。                                                                                    |
| `--hidden`      | 永不应答局域网广播探测（`/shout` 探不到你在）；拿确切地址照常能拨通。                                                               |
| `--no-chain`    | 道别不预约下一把暗号、也不接受别人的预约——对陌生人常开的台席用这个。                                                                |
| `--guard <KEY>` | 常备门禁：每位来客都要对上同一句机器暗号（32 字节随机串），且从不消耗——错钥拨号刷多少次也锁不住台。与 `--no-chain` 同用即武装台席。 |
| `--courier`     | 开茶馆（见[两堵 NAT 墙之后](#两堵-nat-墙之后)）——同一个二进制的另一份工。                                                           |

### 指令一览

| 指令                                | 作用                                                                         |
|-------------------------------------|------------------------------------------------------------------------------|
| `/dial <地址> [暗号]`               | 主动去找人；带暗号则双方必须对上。                                           |
| `/await <暗号>`                     | 备好切口：下一位来客对得上才谈得成（一位一验、验完即焚——端口扫描烧不掉它）。 |
| `/meet <茶馆地址> <房号> [暗号]`    | 经茶馆与事先约好的人碰头（双方报同一房号）。                                 |
| `/punch <介绍人地址> <标签> [暗号]` | 经介绍人尝试 UDP 打洞**直连**（双方报同一标签）。                            |
| `/file <路径>`                      | 递一份文件（≤32MB）给当前对话的人。                                          |
| `/talk <编号\|名字>`                | 在多场并行对话间切换注意力。                                                 |
| `/list`                             | 看当前连着谁。                                                               |
| `/card`                             | 打印自己的名片（名字 + 各网卡地址）。                                        |
| `/shout`                            | 局域网广播"有人吗"，在听的人应答名字和地址。                                 |
| `/circle`                           | 与当前在场的人凑话铸群钥匙（前提：彼此已互连）。                             |
| `/gsay <话>`                        | 圈内发言——加密一次，人人同时收到。                                           |
| `/bye`                              | 与当前对话的人道别。                                                         |
| `/quit` 或 Ctrl-D                   | 与所有人道别后离场；Ctrl-C 直接离场。                                        |

### 群聊

1. 人人互拨成网（全连接——正是这个结构让群里没有窃听位）。
2. 任何人跑 `/circle`——每人贡献一份随机数，群钥匙由全部贡献推导而来：
   无人能独断，也无人能预知。
3. `/gsay <话>`——一份密文，从每条线扇出。
4. 有人新加入？新人先与每个人互连，然后任何人再跑一次 `/circle`——
   这本身就是换钥规则。实用上限约 8 人（N 个人的圈需要 N² 条线；
   更大的聚会需要舞台，那是另一个项目）。

### 两堵 NAT 墙之后

你们俩都能**拨出**——NAT 从不拦出门，问题只在谁接电话。两个答案都内置了：

- **茶馆**——在有公网 IP 的机器上以 `--courier` 跑同一个二进制。它不是特权
  服务器：无身份、无存储、无明文。带外约好同一房号的两位客人被接到一起。
  它看得见谁、何时、多少字节——一个字也看不见。
  ```bash
  # 公网机器上
  ./E2EE-Experiment --courier 0.0.0.0:8888
  # 两边各自从 NAT 墙后
  /meet <茶馆地址> <房号> [暗号]
  ```
- **介绍人（打洞）**——茶馆的 UDP 兼职。想要**直连**的两个人报同一个
  标签，各自得知对方的公网地址，然后同时敲对方的门——各自的 NAT 都以为
  是自己人先出的门，把门开着。尽力而为：墙太严打不通，就手动换 `/meet`
  走茶馆，没有自动回退。

**房号和标签是接头地点，不是秘密**——要挑得难猜（两对人撞号会被接到
一起），并且像暗号一样带外约定。

### 暗号：确认对面是谁

中间人漏洞的解药是一个人类动作：带外约一句暗号（当面、电话——除了这条
线之外的任何渠道），然后这样用：

- `/dial <地址> <暗号>`——握手从此包含一个数学证明：双方持有**同一句**
  暗号。暗号本身从不在任何线上以可推导的形式出现；对不上响亮失败；
  离线爆破不存在。
- `/await <暗号>`——等人来之前，在自己这头备好。
- **暗号链**——道别时可以在已认证的信道里预约下一把暗号，明天的对话
  自动重新认证。它只活在内存里；重启就回到带外再念一次。对陌生人常开
  的台席用 `--no-chain` 整个退出。
- **弱暗号只伤害握手那一瞬**——暗号从不加密对话本身；每场对话的钥匙
  都是全新的临时密钥。

## 给开发者

内核是一个 Rust 库（crate `e2ee`），这个命令行只是它的第一号使用者；
同一个"人"可以住进任何程序——Rust 直接依赖本 crate，其他语言走 C ABI
（`libe2ee.so` / `e2ee.dll`，头文件 `include/e2ee.h`，冻结的只加不改面）。
`cargo test` 覆盖全部行为。设计不变量与红线在

## 已知限制

- **没有存活探测。** 对端不辞而别（断电、拔线，或打洞 UDP 线——UDP 天生
  没有 EOF），那条线和 `/list` 里的条目会一直挂到 `/quit`。
- **介绍人的引荐不认证。** 谁知道标签，谁就能顶替"另一头"报名——
  要确认对面是谁，带暗号。
- **茶馆只按房号配对。** 房号要挑得难猜。
- **群一致性靠约定。** 同时各自重新 `/circle` 对不上拍子会表现为"圈语"
  提醒，再围一次即收敛。一个进程同时只坐一个圈。
- **`--hidden` 不等于隐形。** 只封了广播反射耳；端口扫描器仍能扫到那个
  开着的端口（只是看不出它是什么）。要真正谁都进不来，加 `/await <暗号>`。
- **跨版本聊天单向。** 带垫聊天帧对旧版本不可见（沉默跳过，不显乱码）；
  旧→新照常可读。两端一起升级。
