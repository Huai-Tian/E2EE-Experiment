# E2EE-Experiment
简体中文 | [English](README.md) | [AI 协作文档](README_AGENT.md)

> 一个二进制，像一个人：能听，能说，转身即忘。

**E2EE-Experiment** 把一个比喻当了真：*可执行文件就是一个人。*
没有服务器，没有账户，没有数据库——只有一个替你保守秘密、聊完就忘的程序。

> **使用 AI 助手（Copilot / Claude / GPT 等）参与本项目的开发？** 请先阅读
> [README_AGENT.md](README_AGENT.md)——它专为 AI 编写，包含本项目的设计不变量
> 与红线约束，跳过它直接改代码极可能破坏零持久化内核。

## 对话模型

人怎么交流，它就怎么工作：

| 人                   | 程序                                      |
|----------------------|-------------------------------------------|
| 耳朵                 | 出生即打开 —— 进程一启动就守在端口上      |
| 嘴                   | `/dial` —— 随时主动找人，不必重启         |
| 只有你们俩听得懂的话 | Noise 混成端到端加密（X25519＋Kyber1024） |
| 转身即忘             | 零持久化 —— 任何东西都不落盘              |
| 认出对面是谁         | **你自己来**，解密之后                    |

最后一行是刻意为之。这是安全里的**电话模型**：线路是保密的，
但听筒那头自称是谁，就是谁。系统只承诺**保密**，从不承诺**身份**——
加密从来不等于认证。而"确认对面是真人"这件事，几千年来都是人类用
自己的办法解决的：暗语、共同记忆、一贯的语气。它留在人类手里。

## 设计不变量

项目的灵魂，任何改动不得违背：

1. **一个二进制。** `cargo build --release` 产出一个可执行文件；用 musl 目标
   （`x86_64-unknown-linux-musl`）可得到完全静态的单文件，拷到任何机器就能跑。
2. **零持久化。** 不写配置、不写日志、不存密钥、不留历史。进程就是寿命，
   退出即死亡，死亡即遗忘。消息只在内存——像声音一样，物理上就不可能留存。
3. **无身份层。** 没有账户、没有指纹核对、没有 TOFU。每次连接都是初次见面，
   名字只是自报家门的别名，背后没有任何背书。
4. **对称。** 每份拷贝生而平等。没有服务器/客户端之分，没有特权节点——
   于是也没有值得传唤的节点。
5. **即时性。** 每条连接都用全新的临时密钥做 Noise NN 握手。前向保密是
   自然而然的副产品：会话结束，密钥随之即焚。
6. **署名靠拓扑。** 上屏的名字永远取自来线，绝不取自明文里的自称——
   密码学提供保密，拓扑提供署名。

## 诚实的威胁模型

**能防**：线路上的人（ISP、嗅探 Wi-Fi 的人、骨干网窃听）——
他们看到的只有 Noise 加密帧。

**不防（默认）**：

- **主动的中间人**可以无声地中继握手并读到一切。这是电话模型接受的代价。
  **缓解已内置（可选）**：双方带外约一句暗号，`/dial 地址 暗号`（或等人前
  `/await 暗号`）——PAKE（SPAKE2）让双方在不传输暗号的前提下证明持有同一句，
  对不上则响亮失败。
- **对端本人**。对方可以复制、粘贴、截图、牢记。端到端加密绑定的是信道，
  不是人性。

一个进程就是一个人的完整一生：出生即竖起耳朵，随时可以走向任何人（`/dial`），
也能同时进行多场独立的一对一对话——`/talk` 在其间切换注意力。这些并行的一对一线，
正是将来「围坐一圈」要用的骨架。

## 快速上手

```bash
cargo build --release

# 终端 1 —— Alice 出生，默认在 7777 上听
./target/release/E2EE-Experiment -n Alice

# 终端 2 —— Bob 出生在自己的端口上，然后走去找 Alice
./target/release/E2EE-Experiment -n Bob 127.0.0.1:7778
/dial 127.0.0.1:7777
```

敲一行回车，这一行就会（在途中加密）出现在对面。场内指令：`/dial 地址 [暗号]`
主动找人、`/meet 茶馆 房号 [暗号]` 经茶馆碰头、`/punch 介绍人 标签 [暗号]`
经介绍人打洞直连、`/await 暗号` 备好切口、`/talk` 在多场对话间切换注意力、
`/list` 看在场的人、`/card` 打印名片、`/shout` 同屋喊一圈、`/circle` 围坐、
`/gsay` 圈内发言、`/bye` 与当前对话道别、`/quit` 或 Ctrl-D 与所有人道别后
离场；Ctrl-C 直接离场。带 `--hidden` 隐身出生的人，永远不应答 `/shout` 探测——
只有拿着确切地址或经约定接头的人才找得到。

聊天走 stdout，连接事件走 stderr——对话本身可以直接接管道。

## 穿着命令行外衣的库

内核是一个 Rust 库（crate 名 `e2ee`），这个二进制只是它的第一号使用者。
库不打印任何东西、不读任何输入：动作从方法进——`born` / `born_hidden` /
`dial` / `speak` / `talk_to` / `bye` / `leave`——经历从事件流出（`Met`、
`Heard`、`Left`……）。同一个人，可以住进任何程序里。

接入路径（两条都通了）：Rust 程序直接依赖本 crate；任何能调 C 的语言链接
`libe2ee.so` / `e2ee.dll`——工作区成员 `ffi/`，头文件 `include/e2ee.h`。
ABI 刻意很小（12 个函数：生灭、隐身生、找人、切口、说话、道别、收事件……），
每句柄一个私有运转时，**只加不改**的冻结面。`ffi/ffi_test.c` 是可执行的
契约；`ffi/ctypes_test.py` 证明 Python 也能说这套话。

## 线路协议

- **传输层**：TCP（或打洞出来的 UDP 线——同样的帧格式，一帧一数据报）
- **帧格式**：每条消息（握手或数据）= `u16 大端长度 + 载荷`
- **对暗号（有暗号时最先）**：双方各交换一条 SPAKE2 遮罩（各约 65 B 的帧）；
  暗号本身从不在任何线上以可推导的形式出现
- **握手**：Noise 混成——无暗号用
  `Noise_NNhfs_25519+Kyber1024_ChaChaPoly_BLAKE2s`，带暗号用
  `Noise_NNpsk0+hfs_25519+Kyber1024_ChaChaPoly_BLAKE2s`（PAKE 的产出作
  PSK）。X25519 与 Kyber1024 每场同上——攻击者必须两道都破。每条握手消息
  约 1.6 KB（一场合计约 3.2 KB）。先 `/dial` 的一方为发起者；茶馆/介绍人
  路径上由它们分主客（后到者发起）
- **握手后第一帧（双向）**：自报的名字——与一切应用数据同样加密（类型
  `0x05`），UTF-8，无签名，纯属装饰
- **聊天帧**：每份加密载荷以一个类型字节开头——`0x00` 聊天行 · `0x01` 暗号
  预约 · `0x02` 预约确认 · `0x03` 凑话 · `0x04` 群密文 · `0x05` 名字。
  不认识的类型沉默跳过（向前兼容）
- **道别**：空明文帧（线上只有一个 AEAD 标签），或直接断开连接
- **时限**：相遇的每一件（对暗号、握手、报名字）都以 10 秒为限——
  连上不说话的，请回，绝不奉陪
- **侧信道——局域网发现（UDP）**：`/shout` 向端口 37777 广播探子；在听的人
  应答「名字＋可拨地址」。只携带在场，不携带谈话，更不携带秘密。

## 围坐一圈 —— 群聊（v1 已实现）

人也围成一圈说话。人人互拨成网（全连接）后，`/circle` 凑话铸钥；`/gsay`
用自己的子钥加密一次、同一份密文从每条线扇出。有人新加入？再围一次——
这本身就是换钥规则。上屏的名字永远取自来线：密码学提供保密，拓扑提供署名。

下面的设计定稿是它的完整论证：

- **拓扑——一圈，而非舞台。** 每位成员与其余每人直连（全连接网）。任何想
  省连接的做法——围圈传话、设"主持人"——都必须解密再转述，于是成了窃听者。
  N 个人的圈需要 N² 条线，实用上限约 8 人。这不是缺陷：五百人的圈叫演讲，
  演讲需要舞台（服务器）——那是另一个项目。
- **入圈——引荐。** 新人拨通任意一位在场者；引荐人只递地址清单，别的一概
  不管——绝不转述一个字的谈话内容。随后新人与每个人独立握手成线。
- **成员——在场即成员。** 成员 = 活动连接，任何地方都不存花名册。离线即
  除名；最后一人离场，聚会消亡。
- **屋里的话——一把群钥匙。** 每人现场造 32 字节随机数，经自己的 Noise
  线路广播给全员；所有人各自计算 `K = HKDF(按字节排序后的全部贡献)`——
  无人能独断钥匙，也无人能预知。成对 Noise 的职责收缩为一件小事：牵线成网，
  护送这场协商。
- **发言——加密一次，处处同送。** 每个说话人派生自己的子钥
  `sᵢ = HKDF(K, rᵢ)`——自己的贡献兼职发送者标签；按人派生子钥，避免共用
  钥匙下的 nonce 撞车。同一份密文，从每条线扇出：加群之后，消息同时发给
  所有人。
- **换钥——只由加入触发。** 离开的人没有活线可听，零持久化没有存货可日后
  解密，且下一次任何加入都会重铸钥匙——离开不换钥。想驱逐谁：剩下的人
  重开新场（重新凑话）——这就是加入机制本身，不必发明新东西。
- **署名——线路即署名。** 每一帧仍然从说话人自己的线路发出，任何成员都
  无法替别人开口。铁律：上屏的名字永远取自来线，绝不取自明文里的自称。
  密码学提供保密，拓扑提供署名。
- **诚实的局限。** 贡献经全员广播，任何成员都能推算他人的子钥——但这不
  构成冒名能力，因为注入需要线路，而线路只有本人有。成员各自重新 `/circle`
  若对不上拍子，会有人手里握着不合的群钥匙；解不开的群帧会以「圈语」事件
  提醒（不再无声吞掉）——再围一次即收敛。

## 找到彼此 —— 发现与配对（已实现）

你已经知道每个人都在场——出生即听。问题是在哪找到。零持久化逼出一个干净的
分工：**系统转身即忘，人来记得。** 地址簿在系统之外——在你的纸条上、记性里。
和「认人是人类的职责」同构：*记得对方住哪，也是人类的职责。*

- **同屋喊一嗓子 —— `/shout`（已实现）。** 在局域网 UDP 广播一声「有人吗」，
  在听的人应答名字和可拨地址。主动查询，不是常开信标——没人应，就是屋里没人。
- **隐身 —— `--hidden`（已实现）。** 有的人不应任何喊话。带 `--hidden` 出生
  的人永不应答局域网探测：广播探不到他的存在——那只应声的反射耳朵压根
  没竖。其余一切照旧：TCP 耳朵照常开着，拿着确切地址（名片上来）照样拨得
  通，茶馆/介绍人接头照常。隐身是单向的：隐身者仍可 `/shout` 找别人——但
  喊这一嗓子本身就把自己的 IP 报给了所有在听的人，真隐身连喊也不喊。
- **名片 —— `/card`（已实现）。** 打印你的名字和每个网卡的 `ip:port`。
  抄走、电话里念、当面递都行；只要地址够得着，走遍天下有效。
- **茶馆 —— `--courier`（已实现）。** 给两堵 NAT 墙后的人。同一个二进制的
  另一份工，部署在任意有公网 IP 的机器上：房号由客人自选（带外约定，与
  暗号同一条路），茶馆只认号接线。不是特权服务器——无身份、无存储、无
  明文；谁都能开一间，没有哪间茶馆比别的高贵。双方都是主动拨出（NAT 从不
  拦出门），所以这条路永远可用。茶馆看得见谁、何时、多少字节——一个字也
  看不见。
- **介绍人 —— `/punch`（已实现）。** 掌柜的兼职：同一个门牌，UDP 那半边。
  想要**直连**的两个人报同一个标签，介绍人把对方的公网地址分别递给他们，
  随后退场。接着两边同时敲对方的门——各自的门卫都以为是自己人先出的门，
  把门开着。Noise 握手在这条打出来的线上照常进行，介绍人一个字节也没碰过。
  尽力而为（握手消息各约 1.6 KB，走 IP 分片）——墙太严打不通，就手动换
  `/meet` 走茶馆；没有任何自动回退。

**房号 ＋ 暗号（已实现）。** 房号公开——用户带外自选；要挑得像暗号一样
难猜，否则两对人撞了号会被接到一起。暗号私密——同样用户自选、带外携带。
系统从不强制、不存储你的第一句暗号；它的强度是人类的职责，和辨认声音一模
一样。（暗号链上的滚动暗号是唯一的例外：系统生成，但只在已认证的信道里
生，且永不落盘。）两者永远是两个东西。

**PAKE——证明持有暗号，而不出示暗号（已实现）。** SPAKE2 让两个持有同一
暗号的人在数学上互相认证，而暗号从不在任何线上以可推导的形式出现。错的
暗号干净地失败；猜测只能在线发生，而且切口一位一验——备一次只容猜一次，
猜过即焚（没走到对暗号的连接不消耗切口，端口扫描烧不掉你的约定）；离线
暴力破解不存在。

**暗号只点火（已实现）。** PAKE 成功后得到的钥匙只干一件事：护送 Noise
握手（PSK 模式）。谈话用的钥匙全部是每场全新的临时密钥——暗号从不说话。
弱暗号的伤害被锁死在握手一瞬，场末全焚。

**后量子混成握手（已实现）。** 被动录像者可以把今天的流量存着，等量子
计算机折断 X25519 再回放——「先存后解」。本设计的握手就是全部的钥匙
时刻（没有棘轮），更要命的是暗号链逐场传暗号：握手被将来解开，泄出的
不只是旧记录，还有**下一把暗号**——录像者从耳朵变成嘴巴，可以冒充。
所以握手上混成：X25519 与 Kyber1024 同时上，攻击者必须**两道都破**。
绝不纯后量子替换——新数学太年轻（SIKE 2022 年被一台普通电脑攻破），
混成保住四十年老锁作底。代价约每场 3.2 KB（两条各约 1.6 KB 的帧）。PAKE
本身保持经典：它的录像将来即使被解开，泄出的只是一把已用掉的暗号。

**暗号链（已实现）。** 道别时可以在已认证的信道里预约下一把暗号——预约
加确认，没等到确认的预约直接丢弃：失败丢的只是便利，永远不丢安全。链只活
在内存，寿命是两边进程寿命的交集；重启就回到带外再念一次。链锚在地址上：
直连有效；打洞线上的锚是对端的公网映射地址，映射一逝预约就闲着（不出错，
只是用不上）；茶馆线干脆不挂链——房间一次性，没有可挂的锚。滚动暗号永不
落盘——持久化的暗号就是长期凭证，正是本项目刻意删掉的「面孔」。

**一间房只坐两人（已实现）。** 茶馆从不招待一群人。聚会自己织网——每条
线一间双人房，引荐人经既有加密线路把房号和暗号递给双方。每条线各自的
Noise 让转手的帧不可伪造、跨房不可关联；上面的群钥匙表住在比接线更高的
一层，原样不动。

## 已知限制

先说丑话——v1 有这些毛边：

- **没有存活探测。** 对端不辞而别（断电、拔线），或经打洞 UDP 线消失
  （UDP 天生没有 EOF），那条线和 `/list` 里的条目会一直挂着，直到你
  `/quit`。相遇的每个阶段都有时限，但谈成了的对话没有。
- **介绍人的引荐不认证。** 谁知道标签，谁就能顶替「另一头」报名——
  标签是接头地点，不是身份。`meet_via` 只认介绍人本人递来的引荐，但
  介绍人只认标签不认人。要确认对面是谁，带暗号。
- **茶馆只按房号配对。** 两对人挑了同一个房号会被接到一起；房号要
  挑得难猜。
- **群成员的一致性靠约定。** 全连接要手动拨，同时各自重新 `/circle`
  可能使成员手里的群钥匙不一致（表现为圈语提醒，再围一次即好）。
  没有花名册来仲裁——这是刻意的。
- **一人一时一圈。** `/circle` 覆盖当前全部对话；同一个进程坐不进
  两个圈。
- **隐身不等于隐形。** `--hidden` 只封了喊话反射耳；TCP 监听端口照常
  接拨，端口扫描器仍能扫到那个开着的端口（只是看不出它是什么）。要真正
  谁都进不来，再配上 `/await 暗号`。

## 这条路可以往哪走

| 想法                    | 隐喻                     | 必须守住的约束               |
|-------------------------|--------------------------|------------------------------|
| IPv6 优先直连           | 同处一室                 | 本来就是直连                 |
| 扩充 C ABI 表面         | 把动词教给更多语言       | 只加不改；签名永久冻结       |

任何想存消息、验身份、引入特权节点的功能，都破坏了这个模型——
它属于另一个项目。
